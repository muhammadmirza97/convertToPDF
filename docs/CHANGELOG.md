# Changelog

## 2026-07-31 Housekeeping — folder cleanup

### Removed

- `sample_files/` — 413 leftover files from past test runs. The root cause is fixed: the
  `workspace` fixture now uses pytest's `tmp_path`, so tests never write into the project.
- `setup_git.bat` — a one-time bootstrap that deleted `.git` and re-initialised the repo. Its
  job is long done, and a stray double-click would have destroyed the history.
- `convert_to_pdf.py` — a legacy wrapper fully covered by `cli.py auto_to_pdf`. With it went
  the `ACTIONS` and `LEGACY_ACTION_TO_TOOL_ID` tables, `convert_files()`, and the legacy
  branch inside `get_tool()`. There are now exactly two entry points.
- `tests/test_converter.py` — every case in it was already covered by `test_run_tool.py`.
- `__pycache__` folders, `.pytest_cache`, and the 336 KB development `logs/app.log`.

### Changed

- `validate_action()` became `validate_tool_id()`: same job, but it takes a tool id and an
  explicit set of missing dependencies instead of an old action label and a LibreOffice flag.
- Moved `install_shortcut.ps1` and `build_exe.ps1` into `scripts/`, and made both resolve the
  project root from their own location so they work from anywhere.
- `Dockerfile` no longer copies the deleted files and now includes `assets`.
- Rewrote `.gitignore` and `.dockerignore` around the folders that actually exist.
- README project structure now describes the real layout, including `scripts/` and `assets/`.

## 2026-07-31 Version 3.2 — One-click launch and automatic shutdown

### Launching

- Added `assets/app_icon.ico` and `app_icon.png`, generated by `assets/make_icon.py` so the
  design can be regenerated rather than being an opaque binary.
- Added `install_shortcut.ps1`, which creates a "Local PDF Toolbox" desktop icon, optionally
  a Start-menu entry, and can remove both again. The shortcut targets
  `.venv\Scripts\pythonw.exe`, so double-clicking opens the app with no console window.
- The window and taskbar now use the app icon.
- Rewrote `run_app.py` so a startup failure is written to `logs/app.log` and shown in a
  dialog. Without this, a shortcut launched through `pythonw.exe` would fail silently.
- `build_exe.ps1` now passes the icon and bundles the `assets` folder.

### Automatic shutdown

- The app closes itself after 30 minutes with no mouse or keyboard input. Mouse, key, wheel
  and button events are watched with `bind_all`, so the workspace and signature windows count
  as activity too.
- One minute before closing, a countdown window appears with a **Keep working** button. Any
  activity dismisses it.
- A running operation counts as activity, so a long OCR or compression job is never cut off.
- Configurable through `PDF_TOOLBOX_IDLE_MINUTES`; `0` disables automatic closing, and an
  unreadable value falls back to 30 rather than disabling the feature.
- Closing calls `quit()` before `destroy()`, so the event loop ends and the process exits
  cleanly even when CustomTkinter still has timers queued.

### Tests

- Test count raised from 261 to 273, covering the idle clock, the warning window, activity
  dismissal, the running-job exemption, the disabled state, timeout parsing, and an
  end-to-end check that the event loop really ends by itself.
- Verified for real: launched through `pythonw.exe` with a 7-second timeout, the process
  closed itself after 9.2 seconds with exit code 0.

## 2026-07-31 Version 3.1 — Forms and remaining tool options

Closes the last functional gaps against a mainstream online PDF service. The registry now
holds 40 tools. No account or sign-up exists anywhere in the product, by design.

### New tools

- **Fill PDF form** — fill named AcroForm fields from `name=value` lines or JSON, with an
  optional flatten that draws the values as page content and deletes the fields.
- **Create form field** — add a text box, checkbox or dropdown at a millimetre position.
  Across several pages the field name is numbered so each page keeps its own value.
- **List form fields** — writes the fillable fields to a JSON file you can edit and feed
  back into Fill PDF form.
- **Extract images from PDF** — saves the embedded pictures in their original format and
  quality, with a minimum-size filter for icons and hairlines.

### New options

- **Split PDF** gained fixed chunks: `every_n_pages=10` makes pages 1-10, 11-20, and so on.
  Using ranges and chunks together is rejected rather than guessed.
- **Add watermark** gained a tiled mode that repeats the stamp across the whole page.

### Interface

- Added the **form workspace**: every field listed with the right editor per type (entry,
  switch, dropdown), read-only fields disabled, Clear all, and a Use these values button
  that writes JSON back into the tool.
- Workspaces now share one `_apply_workspace_value()` path in the GUI, so adding the second
  one needed no new plumbing.

### Fixes

- Fill PDF form now reports "has no fillable form fields" for a PDF with no fields at all,
  instead of the less helpful "no field named X" message.

### Tests

- Test count raised from 229 to 261, covering form creation, listing, filling, flattening,
  value parsing, the form workspace, image extraction, fixed-size splitting and tiled
  watermarks.

## 2026-07-31 Version 3 — Feature parity MVP

Goal of this pass: match the tool coverage a user expects from a mainstream online PDF
service, entirely offline. This stage brought the registry to 36 tools.

### New tools

- **OCR PDF** — Tesseract through PyMuPDF. Keeps the scanned page image and adds an
  invisible text layer. Language packs are detected and listed; several can be combined
  with `+`. Pages that already have text are skipped by default.
- **Redact PDF** — true removal. Text search, millimetre areas, or all images. Partially
  covered images are rasterised so hidden pixels cannot be recovered.
- **Sign PDF** — place a scanned or hand-drawn signature, with optional name and date
  caption. Blank page list signs the last page only.
- **Compare two PDFs** — Markdown text-difference report and a side-by-side visual PDF that
  marks changed pages.
- **PDF to Word** — LibreOffice Writer PDF import filter.
- **PDF to Excel** — detected tables (ruled, then whitespace strategy) or text lines,
  written with openpyxl.
- **PDF to PowerPoint** — one slide per page with python-pptx; page text goes to the notes.
- **PDF to PDF/A** — PDF/A-1b, 2b or 3b through the LibreOffice Draw export filter.
- **Highlight or strike out text** — highlight, underline, strikeout, squiggly.
- **Add text**, **Add shape** (rectangle, ellipse, line, arrow), **Add image** — positioned
  in millimetres from the top-left of the page.
- **Organize pages visually** — page plan tool backed by a thumbnail workspace.

### Interface

- Added the **Organize workspace** window: page thumbnails, multi-select, rotate left and
  right, move left and right, delete, reset, and a generated page plan.
- Added the **signature pad**: draw with the mouse, choose ink and thickness, saved as a
  trimmed transparent PNG under `output/signatures/`.
- Added drag-and-drop file input through tkinterdnd2, with unsupported files rejected and
  reported. The app still runs when the extension is unavailable.
- The header now reports every optional engine, including detected OCR languages.
- Tools are disabled with the name of the engine they need, not a hard-coded label.
- Added the generic `Tool.workspace` field and the `signature` option kind so interactive
  helpers stay registry-driven instead of special-cased in the GUI.

### Fixes and internals

- `search_text_rects()` replaces a non-existent PyMuPDF flag; exact-case search now
  re-reads each hit, because MuPDF's own search is always case-insensitive.
- Table detection falls back from ruled lines to whitespace columns before giving up.
- `office_tools.convert_with_libreoffice()` now supports import filters, filter options,
  custom output suffixes and a timeout message, and backs all four LibreOffice tools.
- `apply_page_plan()` added to `pdf_pages` so the workspace, the CLI and tests share one
  code path.
- Added `openpyxl`, `python-pptx` and `tkinterdnd2` to the constrained requirements.

### Tests

- Test count raised from 135 to 228, covering every new tool's success and failure paths,
  the Organize workspace, the signature pad, drag-and-drop filtering, thumbnails and page
  plans.
- Added a registry invariant test that every registered option is a real argument of its
  processor, and a coverage test for the expected mainstream tool list.
- OCR and LibreOffice tests skip themselves when the engine is absent.

## 2026-07-31 Version 2 — Essential Local PDF Toolbox

### Architecture

- Added `src/tool_registry.py` as the single source of truth for every tool: accepted
  inputs, options, processor, batching and external dependencies.
- Replaced the action dropdown with a categorized tool dashboard built from the registry.
- Added `run_tool()` in `src/converter.py`, with per-file failure isolation, progress and
  log callbacks, and option coercion. `convert_files()` is kept as a compatibility wrapper.
- Rewrote validation to be registry-driven, so a tool's accepted files, minimum file count
  and dependency messages live with the tool.
- Added `cli.py`, a registry-driven command line with `--list`, `--help-tool` and
  `--set key=value`.
- Added `ToolOutput` so a tool can return outputs plus a note, such as a size saving.
- Renamed the product to Local PDF Toolbox and added `APP_VERSION`.

### New tools

- Organize: Rotate pages, Extract pages, Remove pages, Reorder pages, Insert pages from
  another PDF.
- Optimize: Compress PDF (Low/Balanced/Maximum), Repair PDF.
- Edit: Add watermark (text or image), Add page numbers, Crop pages.
- Security: Protect with password (AES-256), Unlock PDF, Remove metadata.
- Convert: HTML to PDF, PDF to Markdown, PDF to JPG or PNG with DPI, quality, grayscale
  and page selection.

### Improvements

- Every PDF tool now accepts the password of a protected input file.
- Images to PDF gained page size, orientation, fit mode, margin, and one-PDF-per-image.
- TXT to PDF gained font size, page size, orientation and margin, now measures real string
  widths when wrapping, and registers a Unicode TrueType font when one is available.
- Compress PDF never writes a file larger than the original.
- Added an "Open output folder" button and a per-tool option form to the GUI.
- Constrained dependency versions and added `pikepdf` and `cryptography`; dropped the
  unused `img2pdf`.

### Bug fixes

- `sanitize_base_name()` now normalizes `\` and `/` before taking the file stem, so
  Windows-style input names behave identically on Windows and POSIX. This fixes the
  `test_safe_output_path_sanitizes_windows_unsafe_names` failure seen on Linux.
- Corrupt PDFs now raise a friendly "try Repair PDF first" message instead of a raw
  library error.

### Tests

- Increased automated tests from 22 to 135, covering every new tool's success and failure
  paths, orchestration, the CLI, registry invariants, and GUI form building.
- Added invariant tests: inputs are never modified, outputs never overwrite, outputs stay
  inside the chosen folder, no temporary folders are left behind.
